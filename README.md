# Dxrnicord

A lightweight, security-hardened Discord music bot built for multi-platform audio playback, real-time sound customization, and 24/7 live radio.

## Highlights

- **Multi-Source Music Playback** — Searches across YouTube, Spotify, Deezer, and SoundCloud to find the right track, with support for playlists, direct links, and lyrics.
- **Equalizer & Audio Effects** — 15-band equalizer presets, custom bass/mid/treble tuning, speed & pitch controls, and real-time audio filters.
- **24/7 Radio & Continuous Modes** — Live internet radio stations, autoplay, 24/7 voice channel stay mode, and interactive playback buttons.
- **Voice Session Controls** — Session Host privileges with democratic vote-skip for shared voice channels, plus role-based admin customization.
- **Reliability & Security** — Automated audio node failover, input/URL validation, rate limiting, and a full unit test suite.

## Tech Stack

- **Runtime:** Node.js (ESM)
- **Libraries:** `discord.js` v14, `lavalink-client` v2
